# BusinessPulse AI

End-to-end retail business intelligence and decision-intelligence platform: ingestion, data
quality gates, a dbt bronze/silver/gold warehouse on DuckDB, forecasting, churn and CLV
models, alerts, root-cause analysis, a what-if simulator and role-based workspaces for Data
Analysts and Business Analysts.

* **Data:** the real UCI Online Retail II dataset (CC BY 4.0). Inventory and marketing
  modules use clearly labelled synthetic data.
* **Sign-in:** demo identities only — pick a role on the login screen. No real accounts.
* **Source code:** https://github.com/Jahnavilanke/Businesspulse.ai

This Space is deployed automatically from the GitHub repository.
